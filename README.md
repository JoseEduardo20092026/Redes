1. Sobre o projeto:
   Este projeto trata-se de um site desenvolvido com o objetivo de apresentar a área de redes e explicar algumas coisas relacionadas a área.
   Algumas coisas relacionadas a área que o site explica incluem: Profissões relacionadas a área, Onde o profissional da área pode trabalhar, Além de alguns termos em inglês que são usados na área.
   Estes pontos que foram mencionados são apenas alguns dos pontos abordados.   

2. Tecnologias utilizadas
    -HTML5.
    -CSS3
    -FlexBox CSS.
    -Media query

4. Dispositivos aos quais o site pode ser visualizado sem que o layout quebre:
   -Celulares.
   -Tablets.
   -PC's.
